# SPAZE — Mathematical Formulation of the Conditional VAE

## 1. Probabilistic Latent Variable Model
Let $\mathbf{x} \in \mathcal{X}$ denote the observed spatial room configuration vector of an architectural floor plan, and let $\mathbf{c} \in \mathcal{C}$ represent an architectural conditioning variable encoding user preferences (Space-Efficient, Open Layout, Privacy-Focused). 

We assume that layout variations are generated by an underlying continuous latent variable $\mathbf{z} \in \mathbb{R}^{d_z}$ (where $d_z = 8$). The true generative distribution is defined as:
$$p_\theta(\mathbf{x} \mid \mathbf{c}) = \int p_\theta(\mathbf{x} \mid \mathbf{z}, \mathbf{c}) p(\mathbf{z} \mid \mathbf{c}) \, d\mathbf{z}$$

Assuming the latent prior is conditionally independent of $\mathbf{c}$ and follows a standard isotropic Gaussian:
$$p(\mathbf{z} \mid \mathbf{c}) = p(\mathbf{z}) = \mathcal{N}(\mathbf{0}, \mathbf{I})$$

---

## 2. Evidence Lower Bound (ELBO) Derivation
Because the marginal log-likelihood $\log p_\theta(\mathbf{x} \mid \mathbf{c})$ is intractable due to the integral over the high-dimensional latent space, we introduce a variational recognition network (encoder) $q_\phi(\mathbf{z} \mid \mathbf{x}, \mathbf{c})$ parameterized by deep neural weights $\phi$.

Using Jensen's Inequality, we derive the Conditional Evidence Lower Bound ($\text{ELBO}$):
$$\begin{aligned}
\log p_\theta(\mathbf{x} \mid \mathbf{c}) &= \log \int p_\theta(\mathbf{x}, \mathbf{z} \mid \mathbf{c}) \, d\mathbf{z} \\
&= \log \int q_\phi(\mathbf{z} \mid \mathbf{x}, \mathbf{c}) \frac{p_\theta(\mathbf{x}, \mathbf{z} \mid \mathbf{c})}{q_\phi(\mathbf{z} \mid \mathbf{x}, \mathbf{c})} \, d\mathbf{z} \\
&\ge \mathbb{E}_{q_\phi(\mathbf{z} \mid \mathbf{x}, \mathbf{c})} \left[ \log \frac{p_\theta(\mathbf{x}, \mathbf{z} \mid \mathbf{c})}{q_\phi(\mathbf{z} \mid \mathbf{x}, \mathbf{c})} \right] \\
&= \mathbb{E}_{q_\phi(\mathbf{z} \mid \mathbf{x}, \mathbf{c})} \left[ \log p_\theta(\mathbf{x} \mid \mathbf{z}, \mathbf{c}) \right] - D_{\text{KL}}\left( q_\phi(\mathbf{z} \mid \mathbf{x}, \mathbf{c}) \,\|\, p(\mathbf{z}) \right)
\end{aligned}$$

Thus, maximizing the ELBO minimizes the Kullback-Leibler divergence between the variational posterior and the true posterior:
$$\mathcal{L}_{\text{CVAE}}(\theta, \phi; \mathbf{x}, \mathbf{c}) = -\mathbb{E}_{q_\phi(\mathbf{z} \mid \mathbf{x}, \mathbf{c})} \left[ \log p_\theta(\mathbf{x} \mid \mathbf{z}, \mathbf{c}) \right] + \beta D_{\text{KL}}\left( q_\phi(\mathbf{z} \mid \mathbf{x}, \mathbf{c}) \,\|\, \mathcal{N}(\mathbf{0}, \mathbf{I}) \right)$$
where $\beta \in [0, 1]$ represents a cyclical KL annealing coefficient preventing posterior collapse.

---

## 3. Analytical Formulations

### 3.1 Closed-Form Kullback-Leibler Divergence
The encoder outputs variational mean vectors $\boldsymbol{\mu}_\phi(\mathbf{x}, \mathbf{c})$ and diagonal log-variance vectors $\log \boldsymbol{\sigma}^2_\phi(\mathbf{x}, \mathbf{c})$. Because both $q_\phi$ and $p(\mathbf{z})$ are Gaussian, the KL divergence evaluates analytically:
$$D_{\text{KL}}\left( \mathcal{N}(\boldsymbol{\mu}, \operatorname{diag}(\boldsymbol{\sigma}^2)) \,\|\, \mathcal{N}(\mathbf{0}, \mathbf{I}) \right) = -\frac{1}{2} \sum_{j=1}^{d_z} \left( 1 + \log(\sigma_j^2) - \mu_j^2 - \sigma_j^2 \right)$$

### 3.2 Reparameterization Trick
To enable continuous gradient propagation via backpropagation through stochastic sampling nodes, latent vectors $\mathbf{z}$ are sampled via deterministic transformation:
$$\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$$
$$\mathbf{z} = \boldsymbol{\mu} + \boldsymbol{\sigma} \odot \boldsymbol{\epsilon} = \boldsymbol{\mu} + \exp\left( \frac{1}{2} \log \boldsymbol{\sigma}^2 \right) \odot \boldsymbol{\epsilon}$$

### 3.3 Reconstruction Loss Function
For continuous coordinates $(x, y, w, h)$ bounded in $[0, 1]$, Smooth L1 loss ($\text{Huber Loss}$) is applied rather than Mean Squared Error to increase robustness against spatial outlier contours:
$$\mathcal{L}_{\text{recon}}(\mathbf{x}, \hat{\mathbf{x}}) = \sum_{i=1}^M \mathbf{m}_i \cdot \operatorname{Smooth}_{L1}(x_i - \hat{x}_i)$$
where $\mathbf{m}_i \in \{0, 1\}$ is the validity mask and:
$$\operatorname{Smooth}_{L1}(d) = \begin{cases} 
0.5 \, d^2 & \text{if } |d| < 1 \\
|d| - 0.5 & \text{otherwise}
\end{cases}$$

---

## 4. Temperature-Scaled Latent Inference
During inference, diverse alternatives are sampled by introducing a temperature scaling factor $\tau \in [0.5, 2.0]$:
$$\mathbf{z}_{\text{sampled}} = \boldsymbol{\mu} + \tau \cdot \boldsymbol{\sigma} \odot \boldsymbol{\epsilon}, \quad \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$$
- $\tau < 1.0$: Conservative sampling; outputs closely cluster around the most probable centroid.
- $\tau = 1.0$: Standard Gaussian sampling.
- $\tau > 1.0$: Exploratory sampling; explores distant latent modes, producing elevated spatial diversity ($1 - \text{IoU}$).
